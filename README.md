## 🇦🇷 Español

### ¿Qué es esto?

No es solo una agenda. Es un **segundo doctorado personal**.

Este proyecto nació de una idea simple: en lugar de usar una herramienta de productividad existente, **construirla desde cero** — y que ese proceso de construcción sea en sí mismo el aprendizaje.

Cada línea de código escrita para que la agenda funcione es una tecnología nueva dominada. Cada bug resuelto es un concepto que no se olvida más.

### 🎯 El objetivo final

Convertirse en un profesional de alto nivel en tres mundos simultáneos:

- 🧬 **Bioinformática** — NGS, proteómica, fitopatología, workflows modernos
- 💻 **Full Stack Development** — FastAPI, SQL, JS, React, seguridad web
- 🤖 **Machine Learning & IA** — desde los fundamentos matemáticos reales

### 🛡️ La mecánica central — Gatekeepers

La agenda bloquea todas las tareas de estudio hasta que se completen dos hábitos diarios:

| Hábito | Tiempo |
| :--- | :--- |
| 🏃 Deporte matutino | 20–30 min |
| 🗣️ Práctica de idioma | 20–30 min |

Sin hábitos → sin acceso. Simple.

### 🗺️ Hoja de ruta (9 fases)

```
✅ Fase 0 — FastAPI + HTML básico
🔥 Fase 1 — JavaScript puro (DOM, eventos)       ← estamos acá
   Fase 2 — CSS avanzado (Flexbox, Grid)
   Fase 3 — FastAPI endpoints + fetch()
   Fase 4 — SQL con SQLite
   Fase 5 — MySQL en producción
   Fase 6 — Análisis de datos en Python y R
   Fase 7 — Autenticación JWT + seguridad web
   Fase 8 — React
   Fase 9 — Docker + deploy en VPS
```

## 🇺🇸 English

### What is this?

Not just a planner. A **personal second PhD**.

This project was born from a simple idea: instead of using an existing productivity tool, **build one from scratch** — and make that building process the learning itself.

Every line of code written to make the agenda work is a new technology understood. Every bug fixed is a concept that sticks.

### 🎯 The end goal

Becoming a high-level professional across three worlds at once:

- 🧬 **Bioinformatics** — NGS, proteomics, phytopathology, modern workflows
- 💻 **Full Stack Development** — FastAPI, SQL, JS, React, web security
- 🤖 **Machine Learning & AI** — from real mathematical foundations up

### 🛡️ The core mechanic — Gatekeepers

The agenda locks all study tasks until two daily habits are completed:

| Habit | Time |
| :--- | :--- |
| 🏃 Morning exercise | 20–30 min |
| 🗣️ Language practice | 20–30 min |

No habits → no access. Simple.

### 🗺️ Roadmap (9 phases)

```
✅ Phase 0 — FastAPI + basic HTML
🔥 Phase 1 — Vanilla JavaScript (DOM, events)    ← we are here
   Phase 2 — Advanced CSS (Flexbox, Grid)
   Phase 3 — FastAPI endpoints + fetch()
   Phase 4 — SQL with SQLite
   Phase 5 — MySQL in production
   Phase 6 — Data analysis with Python and R
   Phase 7 — JWT authentication + web security
   Phase 8 — React
   Phase 9 — Docker + VPS deploy
```

### 🌐 Project language

> This project is currently developed in **Spanish** as the native language of its author.
> A future goal is to translate it into **English** and possibly a third language —
> in parallel with the language learning that is already part of the project itself.
