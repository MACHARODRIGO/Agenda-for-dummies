# PROYECTO: MASTER PLAN - AGENDA PORTFOLIO
## Visión General
Este proyecto se concibe como un "segundo doctorado" personal de largo aliento (escala de años). El objetivo es la construcción de una herramienta de gestión diaria propia que no solo organice el tiempo, sino que sirva como piedra angular de un portfolio profesional de alto nivel en Bioinformática, Desarrollo Full Stack e Inteligencia Artificial.

---

## I. Objetivos Profesionales y Pilares de Aprendizaje

### 1. Desarrollo y Arquitectura Full Stack
* **Backend:** Dominio de Python mediante frameworks modernos (FastAPI).
* **Bases de Datos:** Implementación y gestión de bases de datos relacionales (MySQL).
* **Frontend:** Diseño de interfaces interactivas y estéticas utilizando HTML5, CSS3 (Flexbox/Grid) y JavaScript.
* **Seguridad:** Integración de protocolos de seguridad web (Autenticación JWT, cifrado, prevención de inyecciones SQL).

### 2. Ciencia de Datos e IA
* **Estadística:** Profundización en estadística avanzada para respaldo científico.
* **Machine Learning & Deep Learning:** Aprendizaje desde los fundamentos matemáticos (Álgebra lineal, Cálculo) hasta la implementación de redes neuronales.

### 3. Integración de Hardware y Sensores
* **Drones:** Manejo y programación de software para integración de telemetría.
* **Cámaras:** Control remoto y captura de datos visuales en tiempo real para sistemas de monitoreo.

### 4. Ciencias Biológicas y NGS
* **Fitopatología:** Expansión del conocimiento en patógenos vegetales.
* **NGS (Next-Generation Sequencing):** Actualización en workflows de secuenciación masiva (Galaxy, automatización en Python/Bash).
* **Proteómica:** Análisis de interacciones de proteínas y modelado molecular.

---

## II. Metodología de la Agenda (The Gatekeepers)
La aplicación implementará una lógica de desbloqueo basada en hábitos:
* **Hábito 1:** Deporte matutino (20-30 min).
* **Hábito 2:** Práctica de idioma (20-30 min).
* **Regla de Negocio:** El resto de las tareas de estudio y desarrollo permanecerán bloqueadas (deshabilitadas visualmente) hasta que se completen los hábitos diarios.

---

## III. Stack Tecnológico
* **Editor:** Visual Studio Code.
* **Backend:** FastAPI (Python).
* **Frontend:** HTML, CSS, JS.
* **Database:** MySQL.
* **Data Analysis:** R y Python (análisis del .log de productividad).
* **Control de Versiones:** Git / GitHub.
